# 日本語 VR — 기초에서 N1까지

**Meta Quest 브라우저에서 하는 일본어 학습 앱. 히라가나부터 JLPT N1까지 매일 할 일을 정해 주고, 차례대로 따라가면 N1까지 가도록 짜여 있습니다.**

- 주소: **https://joyong133.github.io/nihongo-vr/**
- Quest 브라우저에서 열고 **VR로 시작**을 누르면 벚꽃 정원 한가운데에 학습 패널이 뜹니다. PC나 휴대폰 브라우저에서는 **브라우저로 시작**을 누르면 마우스·터치·키보드로 할 수 있습니다.

## 떠먹여 주는 구조

1. **오늘의 학습** 버튼 하나만 누르면 됩니다: 복습 → 새 항목 배우기 → 바로 확인 문제 → 독해·청해 → 결과 요약.
2. 틀린 문제는 같은 세션 안에서 다시 나오고, 배운 항목은 **간격 반복(SRS)** 으로 4시간 → 1일 → 1주 → 1달 → 6달 간격으로 다시 나옵니다.
3. 레벨의 항목을 다 배우면 **모의고사**가 열리고, 합격하면 다음 레벨로 넘어갑니다. 레벨이 오를 때마다 정원의 계절이 바뀝니다(봄 → 여름 → 가을 → 겨울 → 밤 → 황금).
4. 하루 분량은 설정에서 **가볍게(하루 8단어) · 보통(15) · 집중(25)** 중에서 고르고, 로드맵에서 N1까지 남은 예상 일수를 볼 수 있습니다.
5. 이미 아는 레벨이 있으면 처음 설정이나 로드맵에서 그 레벨부터 시작할 수 있습니다.

## 음성

기기의 일본어 음성 합성(Web Speech API)으로 읽어 줍니다. 소리가 안 나오면 기기에 일본어 음성이 설치되어 있는지 확인하세요. `public/audio/` 에 미리 만든 음성 파일(ogg)을 넣으면 그 파일을 먼저 씁니다. 파일 이름 규칙은 `src/core/audio.js` 의 `audioKey` 를 보세요.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 빌드
```

- Three.js (WebGL + WebXR), Vite
- 개발 서버에서 `?iwer`를 붙이면 [IWER](https://github.com/meta-quest/immersive-web-emulation-runtime)로 Quest 3를 에뮬레이션합니다(프로덕션 빌드에는 포함되지 않음).
- `main`에 푸시하면 GitHub Actions가 빌드해서 `gh-pages` 브랜치에 올리고, GitHub Pages가 그 브랜치를 서비스합니다.

## 데이터 다시 만들기

```bash
python3 tools/build_data.py   # 한자·단어 원본을 받아 한국어 뜻·문법·독해·청해와 합쳐 public/data/*.json 생성
node tools/chunk.mjs          # kuromoji로 예문을 문절 단위로 나눔(문장 조립 ★ 문제용)
python3 tools/build_fonts.py  # 쓰인 글자만 모아 Noto Sans JP/KR 서브셋 폰트 생성
```

한국어 뜻과 문법·독해·청해는 `content/` 아래 텍스트 파일에 있습니다.
